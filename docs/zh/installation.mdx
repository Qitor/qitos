## 明确选择安装来源

| 来源 | 安装方式 | 能力身份 |
|---|---|---|
| 已发布 PyPI | `python -m pip install qitos` | 已发布包，**不代表 G5** |
| 可重现 R1 实现源码 | 下方固定 commit 命令 | `f7d4b2d666a156d361da496a41868278f84ffabf` |
| GitHub 开发分支 | `python -m pip install "qitos @ git+https://github.com/WhitzardAgent/WhitzardOS.git@master"` | 会变化，需记录实际 SHA |
| 本地 wheel | `python -m pip install ./qitos-0.6.0-py3-none-any.whl` | 核对 wheel digest 和来源 |
| 框架贡献者 | clone 内 `python -m pip install -e ".[dev]"` | editable checkout，不是 wheel 安装验收 |

G5 源码仍声明版本 0.6.0；仅凭版本号不能区分已发布构建。本轮不发布包。

## 安装本文使用的 runtime

包 metadata 声明 **Python >=3.10**；G5 实测 **3.12.7**，不代表全部声明版本均已验证。
以下命令需要 Git 和 POSIX shell；Windows 需使用对应的 venv 激活命令。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install "qitos @ git+https://github.com/WhitzardAgent/WhitzardOS.git@f7d4b2d666a156d361da496a41868278f84ffabf"
python -m pip install pytest
qit --help
qita --help
```

历史资格 wheel 的 SHA256 为
`e8eb54198c49d8082027a4379fa977b96a685224680aea8242573958db60f980`。
重新构建的归档字节可能不同，应同时核对源码身份。

## 可选依赖

fake 算术入门只需基础包和 pytest。真实 OpenAI 或兼容客户端使用相同固定来源的
`qitos[openai] @ git+https://github.com/WhitzardAgent/WhitzardOS.git@f7d4b2d666a156d361da496a41868278f84ffabf`；
`[models]` 还安装 LiteLLM。`[docker]` 与 `[qita]` 当前不增加 Python 依赖，
但 Docker 仍需可用的 CLI 和 daemon。MCP 使用 `[mcp]`，浏览器工具 `[web]`，
W&B `[wandb]`，MLflow `[mlflow]`。初次运行不需要全部 extras。

## 核验与下一步

两个 help 命令应退出 0。G5 符号导入失败通常表示解释器或旧安装不匹配；
用 `python -m pip show qitos` 核对，并按准确源码重建 venv。
接着阅读[快速开始](/zh/quickstart)。
