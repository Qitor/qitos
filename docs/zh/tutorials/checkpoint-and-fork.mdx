## 学习目标

在真实纯函数工具完成后暂停并退出进程；从不可变 paused head fork，然后 restore 和 steer。parent 与 child 都通过 Session 执行。

## 前置条件

完成[Quickstart](/zh/quickstart)的安装与 lessons 复制；基础包，Python 3.12.7 实测，无真实请求。

## 完整可运行示例

[`examples/tutorials/session_walkthrough.py`](https://github.com/Qitor/qitos/blob/feat/campaign-absorption/examples/tutorials/session_walkthrough.py)

完整目录是唯一执行来源；同目录的 session_walkthrough.py 是公开教学依赖，不依赖仓库 tests。

```bash
python lessons/session_walkthrough.py create --root ./session-run
python lessons/session_walkthrough.py restore --root ./session-run
```

## 预期输出与断言

`tool_output=42; lifecycle=paused; final_result=arithmetic complete; parent head unchanged by fork`

文件内的 assert 验证结果；ID 每次不同。除 board 由 Ctrl-C 关闭外，命令应退出 0。

## CLI 检查

脚本还写入可加载的 agent.json。inspect 只读 SQLite，不解析凭据或创建 Docker。

```bash
session_id=$(python -c 'import json; print(json.load(open("session-run/control.json"))["session_id"])')
qit session inspect --config ./session-run/agent.json --session-id "$session_id"
qita inspect session "$session_id" --logdir ./session-run
```

## 支持边界

SQLite 是持久存储；Memory 即使在 Session 模式也只在当前进程有效。ephemeral 不承诺恢复。先 fork，再用 restore 获取 source 所有权；不能任意 fork restoring/running head。CLI live pause/steer、未解决 approval 的 restore 当前 unsupported。steering 不授予工具权限。

## 常见错误

目录已存在时选一个新 root；导入失败核对安装来源。配置不匹配、缺失扩展或 typed failure 应检查 Trajectory 和迁移页，不能静默重试 unknown 外部效果。
