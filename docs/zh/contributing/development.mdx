## 为 QitOS 贡献

先阅读根 AGENTS.md 与适用目录规则，遵循唯一内核和依赖边界。
文档与示例修改必须同步英文、中文、CHANGELOG 和 README。
完整例子需要实际执行；示意片段明确标记，不能靠跳过省略号宣称通过。
不要把 credential、private endpoint、raw trajectory 或本机路径提交到仓库。

## 本地文档流程

```bash
python -m pytest -q tests/test_tutorial_snippets.py tests/test_docs_golden_paths.py
python scripts/validate_docs.py
```
在独立工具目录安装固定的 Mintlify 与 MDX 版本；见仓库 docs/README.md。preview 不部署站点。框架开发可 editable install，但文档验收还必须在仓库外安装 wheel。
