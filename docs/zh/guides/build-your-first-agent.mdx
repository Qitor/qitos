## 学习目标

编写 StateSchema、AgentModule.decide/reduce 和停止决策。示例通过两个 action 计算 3 和 4 的平方。

## 前置条件

完成[Quickstart](/zh/quickstart)的安装与 lessons 复制；基础包，Python 3.12.7 实测，无真实请求。

## 完整可运行示例

[`examples/tutorials/custom_agent.py`](https://github.com/Qitor/qitos/blob/feat/campaign-absorption/examples/tutorials/custom_agent.py)

完整目录是唯一执行来源；同目录的 session_walkthrough.py 是公开教学依赖，不依赖仓库 tests。

```bash
python lessons/custom_agent.py
```

## 预期输出与断言

`squares complete; completed=2; process_local=true`

文件内的 assert 验证结果；ID 每次不同。除 board 由 Ctrl-C 关闭外，命令应退出 0。

## 支持边界

这是高级 Python 路径：Engine + RuntimeComposition + process-local Memory store。AgentComposition 创建 ConfiguredAgent，不提供任意 agent_override 参数；自定义 AgentModule 使用这里的公共 Engine 路径，跨进程恢复需另配置持久 store/resolver。

## 常见错误

目录已存在时选一个新 root；导入失败核对安装来源。配置不匹配、缺失扩展或 typed failure 应检查 Trajectory 和迁移页，不能静默重试 unknown 外部效果。
