## 学习目标

通过 delegate、spawn、fan-out 在新进程执行四个真实 child Session，再 join 持久结果；本地 resolver 明确选择本教程 worker。

## 前置条件

完成[Quickstart](/zh/quickstart)的安装与 lessons 复制；基础包，Python 3.12.7 实测，无真实请求。

## 完整可运行示例

[`examples/tutorials/work_graph.py`](https://github.com/Qitor/qitos/blob/feat/campaign-absorption/examples/tutorials/work_graph.py)

完整目录是唯一执行来源；同目录的 session_walkthrough.py 是公开教学依赖，不依赖仓库 tests。

```bash
python lessons/work_graph.py --root ./work-run
```

## 预期输出与断言

`durable children=4; join=closed; parent retains ownership`

文件内的 assert 验证结果；ID 每次不同。除 board 由 Ctrl-C 关闭外，命令应退出 0。

## 支持边界

delegate 创建等待结果的 child，spawn 创建分离 child，fan-out 声明集合，join 消费结果。handoff 转移同一 WorkItem 的所有权并 fence 旧 owner，不是 child 或 fork。fork 创建独立 lineage，不推进 source。本完整示例执行 child 操作；handoff 执行属于下一轮 E2E 场景。不承诺分布式调度或外部效果 exactly-once。

## 常见错误

目录已存在时选一个新 root；导入失败核对安装来源。配置不匹配、缺失扩展或 typed failure 应检查 Trajectory 和迁移页，不能静默重试 unknown 外部效果。
