## 学习目标

通过显式 extension factory 注册 contributor、memory source、selector、budget policy 和 compactor；验证选择结果与持久 Trajectory 的 compaction loss。

## 前置条件

完成[Quickstart](/zh/quickstart)的安装与 lessons 复制；基础包，Python 3.12.7 实测，无真实请求。

## 完整可运行示例

[`examples/tutorials/context_memory.py`](https://github.com/Qitor/qitos/blob/feat/campaign-absorption/examples/tutorials/context_memory.py)

完整目录是唯一执行来源；同目录的 session_walkthrough.py 是公开教学依赖，不依赖仓库 tests。

```bash
python lessons/context_memory.py --root ./context-run
```

## 预期输出与断言

`context selected; memory selected; compaction loss recorded`

文件内的 assert 验证结果；ID 每次不同。除 board 由 Ctrl-C 关闭外，命令应退出 0。

## 支持边界

示例对已关闭的算术 exchange 做有 loss 声明的省略，不关闭 codec loss 检查。静态 memory source 由应用拥有且只在进程内存在；Session 持久化不会自动将其变成持久知识库。required context 和不兼容 continuation 必须 fail closed。

## 常见错误

目录已存在时选一个新 root；导入失败核对安装来源。配置不匹配、缺失扩展或 typed failure 应检查 Trajectory 和迁移页，不能静默重试 unknown 外部效果。
