## Learning goal

Read the canonical journal through default_reader, inspect steering and fork lineage, export a redacted public projection and reimport that projection.

## Prerequisites

Complete the [Quickstart](/quickstart) installation and lessons copy; base package, Python 3.12.7 tested, no real model requests.

## Complete runnable example

[`examples/tutorials/session_walkthrough.py`](https://github.com/WhitzardAgent/WhitzardOS/blob/master/examples/tutorials/session_walkthrough.py)

The complete directory is the execution source. Sibling session_walkthrough.py is a public teaching dependency, not a repository test helper.

```bash
python lessons/session_walkthrough.py create --root ./observe-run
python lessons/session_walkthrough.py restore --root ./observe-run
qita board --logdir ./observe-run
```

## Expected output and assertions

`records>0; public_export_lossless=false; board opens locally`

Assertions in the file verify the result; generated IDs vary. Commands exit zero; stop the board with Ctrl-C.

## HTML export and replay

--run uses a logical run ID path under the log directory, not the journal filename. Replay starts a read-only local server; stop it with Ctrl-C.

```bash
run_id=$(python -c 'import json; print(json.load(open("observe-run/control.json"))["run_id"])')
mkdir -p "./observe-run/$run_id"
qita export --run "./observe-run/$run_id" --html ./observe-run/replay.html
qita replay --run "./observe-run/$run_id"
```

## Support boundaries

qita is read-only and owns no execution semantics. Default discovery reads journal and historical trace. Whole reads are complete but currently load all frames; query limits are not total memory bounds. Public export is not a lossless raw backup. CLI qita export produces HTML, while CanonicalTrajectoryExporter produces canonical JSON. Keep private runs out of Git.

## Common errors

Choose a new root if the directory already exists. For missing imports verify the installed source. Inspect Trajectory and the migration page for config mismatch, missing extensions or typed failures; never silently retry unknown external effects.
