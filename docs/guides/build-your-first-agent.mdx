## Learning goal

Write a StateSchema, AgentModule.decide/reduce and a final stopping decision. The example squares 3 and 4 through a two-action batch.

## Prerequisites

Complete the [Quickstart](/quickstart) installation and lessons copy; base package, Python 3.12.7 tested, no real model requests.

## Complete runnable example

[`examples/tutorials/custom_agent.py`](https://github.com/Qitor/qitos/blob/feat/campaign-absorption/examples/tutorials/custom_agent.py)

The complete directory is the execution source. Sibling session_walkthrough.py is a public teaching dependency, not a repository test helper.

```bash
python lessons/custom_agent.py
```

## Expected output and assertions

`squares complete; completed=2; process_local=true`

Assertions in the file verify the result; generated IDs vary. Commands exit zero; stop the board with Ctrl-C.

## Support boundaries

This advanced Python path uses Engine with RuntimeComposition and a process-local Memory store. AgentComposition creates ConfiguredAgent; it has no arbitrary agent_override argument. Use this public Engine path for a custom AgentModule, and configure durable stores/resolvers for cross-process recovery.

## Common errors

Choose a new root if the directory already exists. For missing imports verify the installed source. Inspect Trajectory and the migration page for config mismatch, missing extensions or typed failures; never silently retry unknown external effects.
