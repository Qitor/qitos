## Learning goal

Register contributor, memory source, selector, budget policy and compactor by explicit extension factories. Verify selection and a declared compaction loss in the persisted Trajectory.

## Prerequisites

Complete the [Quickstart](/quickstart) installation and lessons copy; base package, Python 3.12.7 tested, no real model requests.

## Complete runnable example

[`examples/tutorials/context_memory.py`](https://github.com/Qitor/qitos/blob/feat/campaign-absorption/examples/tutorials/context_memory.py)

The complete directory is the execution source. Sibling session_walkthrough.py is a public teaching dependency, not a repository test helper.

```bash
python lessons/context_memory.py --root ./context-run
```

## Expected output and assertions

`context selected; memory selected; compaction loss recorded`

Assertions in the file verify the result; generated IDs vary. Commands exit zero; stop the board with Ctrl-C.

## Support boundaries

The example omits closed arithmetic exchanges with a declared loss; it does not disable codec loss checks. The static memory source is application-owned and process-local; Session persistence does not turn it into a durable knowledge store. Required context and incompatible continuation fail closed.

## Common errors

Choose a new root if the directory already exists. For missing imports verify the installed source. Inspect Trajectory and the migration page for config mismatch, missing extensions or typed failures; never silently retry unknown external effects.
