## Contribute to QitOS

Read root AGENTS.md and applicable directory rules. Preserve one kernel and its
dependency boundaries. Update English, Chinese, CHANGELOG and README together.
Execute complete examples; label illustrative fragments explicitly. Skipping
ellipsis blocks is not proof of a runnable tutorial. Never commit credentials,
private endpoints, raw trajectories or local machine paths.

## Local docs workflow

```bash
python -m pytest -q tests/test_tutorial_snippets.py tests/test_docs_golden_paths.py
python scripts/validate_docs.py
```
Install pinned Mintlify/MDX in an isolated tool directory; see repository docs/README.md. Preview does not deploy the site. Editable installation is useful for framework work, but documentation qualification also requires an outside-repository wheel install.
