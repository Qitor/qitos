| Term | Meaning |
|---|---|
| Agent / AgentModule | Your behavior policy / its implementation contract. |
| Engine | Executes observe → decide → act → reduce → check_stop. |
| Session / Run | Durable execution identity / one execution attempt or interval. |
| Snapshot / Checkpoint | Immutable captured state / persisted recovery identity. |
| WorkItem / Attempt | Owned unit of work / a particular attempt. |
| handoff / delegate / spawn / fork / join | Transfer ownership / awaited child / detached child / independent lineage / collect child results. |
| ToolResult / ArtifactRef | Canonical outcome / resolvable reference to retained bytes. |
| Trajectory / historical trace | Canonical journal facts / compatible older trace files. |
| provider / codec / continuation | Model service adapter / semantic encoding contract / opaque state needed by later requests. |
| sandbox / publication / effect / unknown | Execution boundary / explicit output release / external action / unresolved outcome. |
