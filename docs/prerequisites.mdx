---
title: "Prerequisites"
description: "QitOS G5 · Prerequisites"
---

Use Python >=3.10 (3.12.7 tested), pip, Git and a POSIX shell. Install before invoking qit. Fake arithmetic requires no credentials or Docker and runs only trusted pure functions. Real models need provider extras and an explicit credential resolver; file/command tools need working Docker.
