## Reading key

“Terminal” means the current caller received a terminal signal. It does not
imply that a thread, remote request, subprocess, or child Engine stopped.
“Snapshot” means a durable JSON record could truthfully describe the boundary;
it does not claim the current runtime writes that snapshot.

later package.

There is no “best effort wait” state. A boundary is either proven safe, safely
snapshotted with explicit unresolved work that policy permits, or rejected with
the typed failure above.

## Census conclusion

The current repository contains one main Engine loop but several in-process
child/executor mechanisms. None is a durable scheduler. S1 records their owners
and retirement direction while leaving behavior unchanged. WorkGraph must become
the ownership truth before any nested Engine, fan-out pool, background agent,
or qitos.func future can claim durable child semantics.
